# SITE_ANALYSIS

Project: `Miles-Guo_public_archive`  
Repository: `witnessGIT/Miles-Guo_public_archive`

## Goal

Build a source-traceable, rebuildable archive of public Miles Guo livestream/video records. The archive must not treat any third-party index as the sole source of truth.

## 1. GWINS (`gwins`)

Observed archive entry point:

- `https://www.gwins.org/cn/milesguo/`

Observed characteristics:

- Server-rendered paginated archive.
- The archive currently exposes a large historical inventory (the index page reports 2874 items at the time of analysis).
- List rows expose title/date-style identifiers and text excerpts.
- Detail pages expose a numeric GWINS article id, publish date, title, presenter/entity fields, original GETTR URL, secondary Rumble URL, and in many cases manually organized text/timestamps.
- Pagination uses paths such as `list_2_2.html`.

Archive role:

- Strong source for historical discovery and human-organized text.
- Preserve GWINS numeric article id and its own identifier (for example `20230312_1`).
- Do not overwrite original platform ids with GWINS ids.
- Human-organized text must be stored as `transcript_type=human` or structured segments, never mixed with ASR.

## 2. GHOT (`ghot`)

Observed archive entry point:

- `https://ghot.ai/archive/videos`

Observed characteristics:

- Video archive with searchable detail pages.
- Detail pages can expose archive id, date, title, dimensions, duration, original-platform locator, transcript status, full ASR text and time-addressable ASR segments.
- GHOT explicitly states that video transcription is generated by tools/AI and may contain errors.
- Some records show identifier mismatches between the visible title suffix and GHOT route id. Example captured in Pilot: visible `2023.03.12-1` mapped to route `/archive/videos/2023-03-12-3`.

Archive role:

- Strong source for ASR, duration/resolution and time-addressable segments.
- GHOT route id must be preserved exactly as a third-party id.
- GHOT ASR must use `transcript_type=asr` and must never silently replace human-organized text.
- Identifier discrepancies must be retained in source metadata rather than normalized away.

## 3. GETTR Search (`gettrsearch`)

Observed entry point:

- `https://gettrsearch.com/`

Observed characteristics:

- Search UI for Miles Guo videos.
- Filters include year and short/long video type.
- The server-rendered public page does not currently expose the result dataset; observed page may report failure to load videos when accessed without the site's client-side execution/session.

Archive role:

- Discovery/cross-check source, not the canonical truth source until its underlying public data interface is reliably identified.
- Do not fabricate per-video `gettrsearch` records merely to satisfy three-source coverage.
- Add records only after a specific result URL/id or reproducible query result has been captured.

## Cross-source matching rule

A `LIVE_YYYYMMDD_NNN` record represents one underlying video/live item. Source pages are attached to it only when at least two matching signals are available, preferably:

1. exact original-platform URL/id;
2. date + sequence suffix;
3. strongly matching title;
4. duration/timestamps where available.

Conflicts are preserved in `sources.metadata_json` and are not silently discarded.

## Pilot finding

The first verified Pilot records cover 2023-03-12, 2023-03-13 and 2023-03-14. GWINS and GHOT were matched. The 2023-03-12 record demonstrates why source ids must remain source-specific: GWINS uses `20230312_1`, while the matching GHOT route is `2023-03-12-3` even though its displayed title labels the content `2023.03.12-1`.

## Collection order

1. Build complete lightweight GWINS inventory (metadata only).
2. Enrich a small Pilot with GWINS detail-page data.
3. Match GHOT records and import technical metadata/ASR separately.
4. Identify a reproducible GETTR Search result interface before importing it.
5. Validate uniqueness, provenance and rebuildability.
6. Only then expand to full historical detail collection.
