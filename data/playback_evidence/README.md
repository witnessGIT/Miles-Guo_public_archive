# Repository Playback Evidence

This directory is generated by the repository Playback Evidence Service and is **not a direct worker-write surface**.

Layout:

```text
data/playback_evidence/<CASE_ID>/<SEGMENT_ID>/evidence.json
data/playback_evidence/<CASE_ID>/<SEGMENT_ID>/evidence.md
```

`evidence.json` is machine-readable decoded-media evidence. `evidence.md` is the ordinary-Agent-readable review surface.

Evidence generation alone does not count toward Pilot-60. An active playback claim owner must read the evidence and submit a bundle-bound acceptance under `coordination/playback_acceptances/`. The service then creates a qualifying v2 audit record only after canonical cross-checks pass.

Full videos, clips, audio, raw frames, model files and caches are temporary runner data and are never committed here.
